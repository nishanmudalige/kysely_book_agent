# KyselyTutor — Finnish statisticians, history & geography

This update builds on the **Hockey Personality** version of KyselyTutor and preserves the textbook, custom reader, passage highlighting, bilingual replies, Flo default speech voice, and existing Helsinki-inspired theme.

## What's new

- **Finnish statisticians (purple):** Includes source-checked background on **Seppo Mustonen** and his work on Survo, and his influence on Kimmo Vehkalahti, plus Lauri Tarkkonen, Simo Puntanen, and Vehkalahti himself. Connects to textbook acknowledgements (PDF page 9) and to their external published accounts.
- **Finnish history (blue):** Swedish and Russian periods, independence, the Civil War, the Winter/Continuation Wars, statistical history, and later milestones.
- **Finnish geography (teal):** lakes, islands, Lapland, Åland, cities, regions, climate, and major physical features.
- **Hockey (slate blue):** Existing Jokerit and Finnish NHL player support remains.
- **Existing answer classifications remain:** Green = content supported by textbook; orange = related but outside the textbook; red = genuinely unrelated.
- **English and Finnish:** Answers use the existing `Reply language` setting, and `Automatic / Automaattinen` remains selected until the visitor manually changes it.
- **Conservative follow-up support:** Short pronoun questions such as “What did he contribute?” after a Mustonen question keep the correct topic.

### Provenance

These culture and biographical topics are **outside the textbook's main scope**. The agent is told not to attribute general historical/biographical facts to the book, to provide links for claims grounded in its background notes, and never to invent live facts. The text on textbook page 9 may be cited as the book's *acknowledgements*, but it is not a substitute for external biographies. **The app does not browse the live web for historical or geographical questions.** General answers are generated by Claude from preloaded, source-checked background notes; questions about recent or changing facts should be independently verified.

## Files changed / added

- `app.py` — routes the three new optional topics to a separately labelled Claude mode; leaves direct textbook questions on the original retrieval path.
- `finland_topics.py` **(new)** — topic recognition and carefully sourced Finnish background notes.
- `static/app.js` — localized status labels for five subjects (book, related, off-topic, hockey, Finnish statisticians/history/geography).
- `static/style.css` — matching readable colours in light and dark mode.
- `tests/test_finland_topics.py` **(new)** — offline tests for languages, named people, routing, and follow-up scope.
- `README.md` — notes on new topic categories.

## Install in existing GitHub/Render repository

Extract the **update ZIP** into the root of `kysely_book_agent`, retaining the directory layout and replacing existing files.

```bash
git add app.py finland_topics.py static/app.js static/style.css tests/test_finland_topics.py README.md FINLAND_PERSONALITY_UPDATE.md
git commit -m "Add Finnish statisticians history and geography personality"
git push origin main
```

No extra pip dependencies or environment variables are necessary.

### Test

```bash
python -m unittest discover -s tests -p 'test_finland_topics.py' -v
python -m unittest discover -s tests -v
```

- `Mikä oli Lauri Tarkkosen merkitys Vehkalahden tutkimuksessa?`
- `Tell me about the history of Finland.`
- `Missä on Saimaa, ja miksi se on tunnettu?`
